## Selected work

**SmoothBooking** — Booking and queue management for service businesses
Transaction-based booking logic that prevents double-booking, role-based access control enforced in Firestore security rules, and a CI/CD pipeline running unit, end-to-end and security-rules tests against Firebase emulators.
`Next.js 16` `TypeScript` `Firebase` `Expo` `React Native` — private repository

**[Kazakhstan Trip Planner](https://github.com/veikkope/kazakstan)** — Offline-first travel PWA
Built for a real two-week trip: clustered map of 66 destinations, four fully translated languages, and a hand-written service worker with two-tier caching that provisions every page, photo and map tile for zero-signal use. Type-enforced i18n turns a missing translation into a build failure.
`Next.js 16` `TypeScript` `Leaflet` `next-intl` `Service worker` — **[Live demo](https://kazakstan.vercel.app)**

**UAV Tracking** — Drone detection and gimbal control for LeViteZer Oy
Local YOLOv11 detection served over FastAPI, a browser canvas overlay drawing detections on the live video feed, and closed-loop auto-track that keeps a selected drone centred on a direct-drive stabilised pan–tilt head.
`Python` `FastAPI` `YOLOv11` `JavaScript` `Node.js` — private repository

**[Klubi](https://github.com/veikkope/klubi)** — Website project built with TypeScript
`TypeScript` — **[Live](https://klubi-blond.vercel.app)**
